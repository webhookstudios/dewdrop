# Dewdrop 1.1.0

Dewdrop is the new name for Snip. It now has the Sedge look shared by every webhookstudios app: one set of colors, fonts and icons, in light and dark mode.

- New icon, colors and fonts. Window titles and headings use the Sedge serif.
- The top-bar icon and the app icon now match.
- Menus use sentence case, and "Preferences" is now "Settings".
- Screenshots are still named "Snip <date>" by default, so your files sort as before.
- The package and command are now called `dewdrop` (it was `snip`). Installing it replaces the old package.
- If Snip was turned on, Dewdrop turns on in its place the next time you log in.
- Your settings from Snip are copied over the first time Dewdrop starts.
- Everything works exactly as before. Your settings and presets carry over.

Install:

```bash
sudo apt install ./dewdrop_1.1.0_all.deb
```
